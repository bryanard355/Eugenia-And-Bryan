# Eugenia Countdown

This project is a countdown webpage dedicated to Eugenia and Bryan, counting down to their meeting on October 15, 2026. The page features a visually appealing design with interactive elements that engage users.

## Project Structure

- `index.html`: Contains the HTML structure for the countdown page, including styles, scripts, and content related to the countdown to a specific date.
- `README.md`: This documentation file.

## Features

- A countdown timer that updates in real-time.
- Interactive "This or that" choices to engage users.
- Flip cards to reveal fun facts about Eugenia.
- A reveal button that displays a heartfelt message from Bryan.

## Setup Instructions

1. Clone the repository to your local machine:
   ```
   git clone <repository-url>
   ```

2. Navigate to the project directory:
   ```
   cd eugenia-countdown
   ```

3. Open `index.html` in your web browser to view the countdown page.

## Usage

Simply open the `index.html` file in a web browser to see the countdown timer and interact with the features. The page is designed to be responsive and should work well on both desktop and mobile devices.
